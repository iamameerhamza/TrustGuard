# 💎 Impeccable Skill - Code Craftsmanship & Flawless Engineering

This skill equips Antigravity with strict quality standards to ensure all code, architecture, and user interfaces are engineered to impeccable standards.

---

## 1. 🛡️ Defect-Free Engineering Principles
- **Never Swallowing Errors**: Always log or handle exceptions explicitly with clear diagnostic messages.
- **Strict Null & Undefined Guards**: Verify object initialization before property dereferencing (`obj?.prop` or explicit non-null checks).
- **Exact Contract Preservation**: Match method signatures, API payload types, and database schemas strictly without guessing.

---

## 2. ⚡ Code Craftsmanship & Clean Architecture
- **Single Responsibility Principle (SRP)**: Keep functions and components small, focused, and re-usable.
- **Pristine Formatting**: Preserve existing docstrings, maintain consistent indentations, and use clean modular imports.
- **Zero Dead Code**: Remove debug logs, unused imports, and commented-out code before finalizing.

---

## 3. 🎨 Impeccable User Experience (UI/UX)
- **Complete State Handling**: Always provide 4 distinct states for interactive views:
  1. `Loading`: Smooth spinner or skeleton placeholder.
  2. `Error`: Helpful alert message with retry action.
  3. `Empty`: Friendly empty-state graphic/prompt.
  4. `Success`: High-contrast, beautifully styled data view.
- **Pixel-Perfect Micro-Interactions**: Smooth hover effects, 60fps transitions, and active touch feedback.

---

## 4. 🧪 Rigorous Automated Verification
- **Test Before Declaring Victory**: Always run automated test suites (`pytest`, `npm test`, `vite build`) to verify changes empirically.
- **Edge Case Coverage**: Test empty inputs, invalid types, boundary numbers, and network failure modes.
