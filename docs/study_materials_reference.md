# Essential Study Materials Reference

Curated resources for building TrustGuard.

---

### 1. FastAPI
[FastAPI Official Tutorial](https://fastapi.tiangolo.com/tutorial/) — `/scan` route setup, Pydantic validation, Swagger UI docs.

### 2. OpenPhish
[OpenPhish Feeds Documentation](https://openphish.com/phishing_feeds.html) — JSON structure of live phishing feeds: Targets, ASNs, Drop Accounts.

### 3. URLhaus
[URLhaus API Documentation](https://urlhaus.abuse.ch/api/) — Specialized feeds (Country, ASN, TLD) and fetch-frequency limits (no more than every 10 minutes).

### 4. URL Parsing
[Python urllib.parse Documentation](https://docs.python.org/3/library/urllib.parse.html) — Safe handling of complex URLs: scheme, netloc, paths.

### 5. ML Evaluation
[Scikit-Learn Classification Metrics](https://scikit-learn.org/stable/modules/model_evaluation.html) — Why Accuracy is misleading for imbalanced datasets. Precision, Recall, F1, ROC-AUC.

### 6. Explainable AI
SHAP/LIME principles for extracting feature importance and presenting readable security alerts to reduce alert fatigue.
